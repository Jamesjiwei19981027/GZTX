# 01 - 需求分析文档

> 本文档详细描述工作待办提醒系统的功能需求、用户场景、以及竞品分析。

---

## 一、项目背景

在日常工作中，我们面临大量待办事项：会议、报告、代码审查、客户沟通等。如果没有有效的管理工具，很容易出现遗漏或延误。市面上虽有众多待办应用，但存在以下痛点：

- **数据隐私**：个人工作数据存储在第三方服务器
- **功能冗余**：大量用不到的功能，界面复杂
- **提醒不及时**：错过重要事项的通知
- **平台割裂**：电脑端和手机端数据不同步

本项目旨在打造一个**简洁、高效、自主可控**的待办管理系统。

---

## 二、用户画像

### 目标用户

| 用户类型 | 特征 | 核心需求 |
|---------|------|---------|
| 职场人士 | 需要管理日常工作任务 | 快速记录、及时提醒、完成跟踪 |
| 自由职业者 | 多项目并行管理 | 分类管理、优先级排序、时间规划 |
| 学生/研究者 | 课程作业、论文进度 | 截止日期提醒、重复任务、进度统计 |

### 使用场景

1. **早晨规划**：上班前查看今日待办，合理安排时间
2. **临时记录**：会议中快速记录新任务
3. **截止提醒**：任务到期前收到提醒，避免延误
4. **晚间复盘**：查看今日完成情况，规划明日工作
5. **周报生成**：基于完成数据自动生成工作周报

### 3.2 功能详细说明

#### 3.2.1 任务创建

**输入字段**：
- 任务标题（必填，最多100字）
- 任务描述（选填，最多500字）
- 截止日期（选填，精确到分钟）
- 优先级（选填：高/中/低，默认中）
- 分类（选填，从已有分类选择）
- 标签（选填，多选）
- 提醒时间（选填：截止前15分钟/30分钟/1小时/1天/自定义）
- 是否重复（选填：不重复/每天/每周/每月/每年/自定义）

**快捷创建**：
- 支持自然语言快速创建："明天下午3点提醒我写周报"
- 支持语音输入（小程序端）

#### 3.2.2 任务列表

**视图模式**：
- 列表视图：简洁列表，显示标题、截止日期、优先级
- 看板视图：按状态分栏（待办/进行中/已完成）
- 日历视图：在日历上显示任务分布

**筛选排序**：
- 按状态筛选：全部/待办/已完成
- 按优先级筛选：高/中/低
- 按分类筛选
- 按日期筛选：今天/明天/本周/本月/自定义
- 排序方式：截止日期/优先级/创建时间/自定义拖拽

#### 3.2.3 提醒通知

**提醒方式**：
- Web端：浏览器桌面通知（PWA）
- 小程序：微信订阅消息
- 邮件通知（可选）
- 声音提醒（可选）

**提醒策略**：
- 任务创建时设置提醒时间
- 支持多次提醒（如截止前1天、1小时各提醒一次）
- 逾期任务持续提醒（可配置）
- 每日晨报：每天早上推送今日待办概览

#### 3.2.4 重复任务

**重复规则**：
- 每天：每个工作日或每天
- 每周：指定星期几
- 每月：指定日期
- 每年：指定月日
- 自定义：每N天/周/月

**重复任务处理**：
- 完成一次后自动生成下一次
- 可单独修改某次实例而不影响序列
- 可暂停/恢复重复序列

## 四、非功能需求

### 4.1 性能需求

| 指标 | 目标值 |
|------|--------|
| 页面加载时间 | < 2秒 |
| API响应时间 | < 200ms（P95） |
| 首屏渲染时间 | < 1.5秒 |
| 并发用户数 | 支持100+同时在线 |

### 4.2 可用性需求

| 指标 | 目标值 |
|------|--------|
| 系统可用性 | 99.5% |
| 数据备份 | 每日自动备份 |
| 故障恢复 | < 5分钟 |

### 4.3 安全需求

- 用户密码使用 bcrypt 加密存储
- API 通信使用 HTTPS
- JWT Token 设置合理过期时间
- 防止 SQL 注入、XSS、CSRF 攻击
- 敏感操作需要二次确认

### 4.4 兼容性需求

| 平台 | 要求 |
|------|------|
| Web端 | Chrome 90+, Firefox 88+, Edge 90+, Safari 14+ |
| 移动端 Web | iOS Safari 14+, Android Chrome 90+ |
| 微信小程序 | 基础库 2.30.0+ |
| 桌面端 | 支持 PWA 安装（Windows/Mac/Linux） |

## 五、竞品分析

### 5.1 直接竞品

#### Microsoft To Do

| 维度 | 评价 |
|------|------|
| 优点 | 与微软生态深度整合，界面简洁，免费 |
| 缺点 | 国内同步不稳定，功能相对简单，无微信小程序 |
| 可借鉴 | 简洁的UI设计，"我的一天"聚焦功能 |

#### 滴答清单 (TickTick)

| 维度 | 评价 |
|------|------|
| 优点 | 功能全面，全平台支持，习惯打卡，番茄钟 |
| 缺点 | 高级功能收费，界面略显复杂，数据在第三方 |
| 可借鉴 | 丰富的任务属性，智能清单，日历视图 |

#### Notion

| 维度 | 评价 |
|------|------|
| 优点 | 极度灵活，可自定义数据库，All-in-one |
| 缺点 | 学习成本高，国内访问慢，不适合纯待办场景 |
| 可借鉴 | 数据库视图切换（列表/看板/日历） |

#### 飞书/钉钉待办

| 维度 | 评价 |
|------|------|
| 优点 | 企业场景强，有机器人提醒，协作功能完善 |
| 缺点 | 偏企业化，个人使用有门槛，功能受限 |
| 可借鉴 | 与IM结合的提醒方式，任务指派 |

### 5.2 间接竞品

- **番茄ToDo**：专注计时+待办，适合需要专注场景
- **Forest**：游戏化专注，适合学生群体
- **Google Tasks**：极简，但国内不可用

| 重复任务 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 分类标签 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 提醒通知 | ✅ | ✅ | ✅ | ✅ | ✅ |

### 5.4 本项目的差异化优势

1. **数据完全自主**：自托管，数据存储在自己的服务器
2. **开源免费**：无功能限制，可自由定制
3. **轻量专注**：只做待办管理，不堆砌无关功能
4. **微信生态**：深度整合微信小程序，符合国内使用习惯
5. **PWA支持**：Web端可安装为桌面应用，接近原生体验

## 六、用户旅程地图

### 6.1 新用户首次使用

```
发现项目 → 访问Web端 → 注册账号 → 创建第一个任务 → 设置提醒
   ↓                                              ↓
 扫码/链接                                    体验核心功能
   ↓                                              ↓
了解项目价值 ← 收到提醒 ← 完成任务 ← 查看任务列表
```

### 6.2 日常用户使用

```
早晨：打开应用 → 查看"今日待办" → 规划工作顺序
   ↓
工作中：收到提醒 → 处理任务 → 标记完成/延后
   ↓
临时：快速记录新任务 → 设置截止日期
   ↓
晚间：查看完成统计 → 规划明日任务
```
