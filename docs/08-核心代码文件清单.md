# WorkTodo 核心代码文件清单

> **更新**：2026-07-18  
> 以根目录现役代码为准。历史 `docs/worktodo` 快照已删除。

## 一、后端（`backend/`）

| 路径 | 职责 |
|------|------|
| `app/main.py` | 应用入口、CORS、定时任务、路由挂载 |
| `app/core/config.py` | 环境配置 |
| `app/core/security.py` | JWT / 密码哈希 |
| `app/core/dependencies.py` | 当前用户 / DB 会话依赖 |
| `app/db/session.py` | 异步/同步引擎与会话 |
| `app/api/v1/auth.py` | 注册登录 / 微信登录 / 刷新 |
| `app/api/v1/tasks.py` | 任务 CRUD / 统计 / 完成 |
| `app/api/v1/categories.py` | 分类 |
| `app/api/v1/tags.py` | 标签 |
| `app/api/v1/reminders.py` | 提醒 |
| `app/api/v1/users.py` | 用户资料 |
| `app/api/v1/notifications.py` | Web Push / SMTP / 测试通知 |
| `app/api/v1/attachments.py` | 任务附件 |
| `app/api/v1/wx.py` | 小程序配置与订阅消息 |
| `app/models/*.py` | ORM：User / Task / Category / Tag / Reminder / Attachment / … |
| `app/schemas/*.py` | Pydantic 请求响应 |
| `app/services/*` | 提醒、邮件接收解析、任务邮件、微信 |
| `app/utils/*` | email / web_push / wechat / sms / jpush |

| 路径 | 职责 |
|------|------|
| `src/main.ts` | 入口、主题、Element Plus、SW |

| `src/layouts/SidebarLayout.vue` | 侧栏（仪表盘/任务/日历/设置） |
| `src/views/DashboardView.vue` | 仪表盘 |
| `src/views/TaskListView.vue` | 任务列表 |
| `src/views/TaskDetailView.vue` | 任务详情/新建 |
| `src/views/CalendarView.vue` | 日历 |
| `src/views/SettingsView.vue` | 设置 / SMTP / 主题 |
| `src/views/LoginView.vue` | 登录注册 |
| `src/stores/auth.ts` / `task.ts` | 状态 |
| `src/api/*` | API 客户端 |
| `src/components/ReminderSetting.vue` 等 | 任务相关组件 |
| `src/composables/useWebPush.ts` / `useTheme.ts` | 推送与主题 |
| `src/assets/main.css` | MD3 token + Tailwind |

**现役页面**：`InboxView` / `KanbanView` / `MessagesView` 均为真实后端驱动；历史 Mock 壳页不再作为运行路径。
