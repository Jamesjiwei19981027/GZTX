# WorkTodo 核心代码文件清单

> 本文档列出整个项目中所有承载核心逻辑的代码文件，按模块分类。

---

## 一、后端核心文件（Python / FastAPI）

| 序号 | 文件路径 | 职责描述 | 核心逻辑说明 |
|------|---------|---------|-------------|
| 1 | `backend/app/main.py` | 应用入口 | FastAPI 应用实例创建、中间件注册（CORS）、路由挂载、全局异常处理 |
| 2 | `backend/app/database.py` | 数据库配置 | SQLAlchemy 引擎创建、SessionLocal 会话工厂、Base 声明基类、数据库连接管理 |
| 3 | `backend/app/core/config.py` | 全局配置 | 环境变量读取、数据库 URL 配置、JWT 密钥、微信 AppID/Secret 等配置项 |
| 4 | `backend/app/core/security.py` | 安全模块 | JWT Token 生成与验证、密码哈希与校验（bcrypt）、OAuth2 鉴权 |
| 5 | `backend/app/api/deps.py` | 依赖注入 | `get_db()` 数据库会话依赖、`get_current_user()` 当前用户获取依赖 |
| 6 | `backend/app/api/auth.py` | 认证路由 | 用户注册、账密登录、微信登录、Token 刷新 |
| 7 | `backend/app/api/todos.py` | 待办路由 | 待办 CRUD、状态变更、优先级设置、截止日期管理、分页查询 |
| 8 | `backend/app/api/categories.py` | 分类路由 | 分类 CRUD、分类下待办关联查询 |
| 9 | `backend/app/api/users.py` | 用户路由 | 用户信息查询、更新头像/昵称、用户偏好设置 |
| 10 | `backend/app/models/user.py` | 用户模型 | User 表定义：id、openid、unionid、phone、avatar、name、created_at |
| 11 | `backend/app/models/todo.py` | 待办模型 | Todo 表定义：id、title、description、status、priority、due_date、user_id |
| 12 | `backend/app/models/category.py` | 分类模型 | Category 表定义：id、name、color、user_id |
| 13 | `backend/app/models/todo_category.py` | 关联模型 | Todo-Category 多对多关联表 |
| 14 | `backend/app/schemas/user.py` | 用户Schema | 用户相关 Pydantic 模型：注册/登录请求体、用户响应体 |
| 15 | `backend/app/schemas/todo.py` | 待办Schema | 待办相关 Pydantic 模型：创建/更新请求体、响应体 |
| 16 | `backend/app/schemas/category.py` | 分类Schema | 分类相关 Pydantic 模型：创建/更新请求体、响应体 |
| 17 | `backend/app/services/auth_service.py` | 认证服务 | 用户注册逻辑、密码验证、JWT 签发、微信 code2session 调用 |
| 18 | `backend/app/services/todo_service.py` | 待办服务 | 待办业务逻辑：创建/查询/更新/删除、状态流转、统计 |
| 19 | `backend/app/services/category_service.py` | 分类服务 | 分类业务逻辑：创建/查询/更新/删除、待办关联管理 |
