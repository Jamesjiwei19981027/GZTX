# T01 登录注册

> 可直接整段粘贴给执行的 AI。前置：T00 已合入。执行前先读 `docs/app-native-rewrite/00-总计划.md` 第五、六、七节，以及 `app/lib/design/README.md`。

## 目标

原生实现登录、注册、验证码登录、注册后双验证（邮箱 + 手机）、手机号未验证的一周提醒。

## 范围

- 只能改：`app/lib/features/auth/`、`app/test/features/auth/`。
- 共享部分（接口客户端、登录态、控件）只用不改；要改写“共享改动申请”。

## 功能真源（先读）

- `frontend/src/mobile/features/auth/MobileAuthScreens.tsx`
- `frontend/src/components/PhoneVerificationReminder.tsx`、`frontend/src/utils/phoneReminder.ts`
- `frontend/src/App.tsx` 中 LoginGate／VerifyGate 的进入条件
- 接口：Swagger「认证」「用户」分组（`/auth/login`、`/auth/login-code`、`/auth/send-code`、`/auth/register`、`/auth/refresh`、`/users/me/verification/*`）

## 步骤

1. 登录页：账号（用户名／邮箱／手机号）+ 密码；切换到验证码登录；注册入口。错误信息用后端返回的中文。
2. 注册页：按网页版字段与校验规则；发送验证码按钮倒计时；限流提示。
3. 验证门：登录后邮箱或手机未验证时进入验证页，规则对照 VerifyGate。
4. 手机号提醒：已验证显示绿色“已验证”，未验证置灰；未验证用户一周内每次打开 APP 提示一次（规则对照 `phoneReminder.ts`）。
5. 登录成功后交给 T00 的登录态加载用户、公司、项目，进入“工作”Tab。退出登录清空令牌。

## 验收标准

- 总计划第六节全部条件。
- 组件测试覆盖：密码错误、验证码倒计时、未验证进入验证门、提醒一周规则（用固定时间测试）。
- 安卓模拟器实测：测试账号密码登录 → 进入工作 Tab → 退出登录 → 验证码登录（开发环境验证码会回显在接口响应或后端日志里）。
