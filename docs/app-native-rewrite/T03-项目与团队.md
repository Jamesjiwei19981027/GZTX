# T03 项目与团队

> 可直接整段粘贴给执行的 AI。前置：T00 已合入。执行前先读 `docs/app-native-rewrite/00-总计划.md` 第五、六、七节，以及 `app/lib/design/README.md`。

## 目标

原生实现项目切换、新建项目、新建公司、项目概览与设置、邀请成员与接受邀请、团队成员列表与成员详情。

## 范围

- 只能改：`app/lib/features/projects/`、`app/test/features/projects/`。
- 切换项目后更新 T00 提供的“当前项目”全局状态，不自己另存。

## 页面与功能真源（先读，路径相对 `frontend/src/`）

| 屏幕名 | 内容 | 网页源文件 |
|------|------|------|
| project-switch | 项目切换（含“全盘概览”） | `mobile/features/projects/MobileProjectScreens.tsx` |
| project-create / company-create | 新建项目、新建公司 | 同上 |
| project-overview / project-settings | 项目概览、设置、归档、退出项目 | 同上 |
| project-invite / invite-accept | 邀请链接生成、接受邀请（含深链接打开） | 同上、`utils/deepLink.ts` |
| me-team / me-member-detail | 团队成员、成员角色与状态 | `mobile/features/projects/MobileTeamScreens.tsx`、`components/views/TeamView.tsx` |

接口：Swagger「项目」「企业」分组。

## 要点

- 邀请链接要能被系统分享（iOS 分享面板 / 安卓分享），需要时申请 `share_plus` 依赖。
- 接受邀请的深链接：本任务实现页面与处理逻辑；系统级链接注册（iOS Universal Links / 安卓 App Links）放到 T10。
- 删除、归档、退出均需二次确认，文案对照网页。

## 验收标准

- 总计划第六节全部条件。
- 组件测试覆盖：无项目时的空状态与引导新建、切换项目后全局状态更新、非管理员看不到管理操作。
- 安卓模拟器实测：新建项目 → 切换 → 生成邀请 → 用第二个测试账号接受邀请 → 成员列表出现该成员。

## 必须回传的证据

1. 文件清单；2. `flutter analyze`、`flutter test test/features/projects` 输出末尾；3. 每页 iOS／安卓 golden 图路径；4. 模拟器实测截图；5. 与网页版不一致之处；6. 共享改动申请（如有）；7. 发现的接口问题。
