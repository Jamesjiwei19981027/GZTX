## 五、给后续任务的用法说明

完整的开发者指引已写入 `app/lib/design/README.md`，涵盖：
1. **如何发起网络请求**：使用 `context.apiClient` 或 `ApiClient()`，自动处理 `--dart-define=API_BASE_URL`、Bearer 令牌携带与 401 单飞续期；后端 `{code, message, data}` 信封自动解包；异常结构化捕获（`ValidationException`, `ApiException`, `NetworkException`）。
2. **如何获取与管理全局状态**：使用 `context.currentUser`、`context.currentCompany`、`context.currentProject`；通过 `context.authStateRead.selectCompany()` 或 `selectProject()` 进行切换。
3. **如何注册页面与路由**：在各自目录下的 `features/<模块>/routes.dart` 中追加子路由，命名严格对齐 `REGISTERED_SCREENS`；使用 `AppBackScope(isDirty: ...)` 保障返回拦截。
4. **如何写双平台截图与无障碍适配测试**：使用 `testAdaptiveGolden(tester, widget, goldenFileNamePrefix)` 生成 iOS 与 Android 截图；使用 `ResponsiveChecker.checkAdaptiveLayout()` 校验 320 窄屏、430 宽屏、系统字号 200%、深色模式下的布局安全性。
