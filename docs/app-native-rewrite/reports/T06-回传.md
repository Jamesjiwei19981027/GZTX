## 五、与网页版不一致之处

逐条对照 `frontend/src/components/PersonalKnowledgeSpace.tsx`、`ProjectKnowledgeSpace.tsx`、`KnowledgeDialog.tsx` 与两份设计说明：

1. **关联图实现**：网页用 `@xyflow/react`（缩放、平移、从连接点拖线建关联）；原生用自绘节点+曲线箭头，支持拖动画布、拖动节点并保存坐标、点开节点，**不支持从连接点拖线建关联**。任务文件允许"不必做复杂编辑"；手动建关联保留在「更多 → 手动调整关联」。
2. **浮层关闭方式**：网页点遮罩可关闭（有未保存内容时二次确认）；原生底部浮层禁用遮罩点击与下滑关闭，只能点右上角关闭或系统返回，返回时若有未保存内容会二次确认。这样避免误触丢内容，代价是少一种关闭手势。
3. **语音能力**：网页有「语音输入 / 选择音频转文字 / 重试转写」三个入口；原生本期只有「语音输入」一个按钮，转写走同一个 `/asr/transcribe`，**没有音频文件选择入口**（需要文件选择插件）。且当前构建未接入录音插件，点击会明确提示不可用（见第六节 S1）。
4. **项目总结草稿恢复**：网页把草稿 id 存 `sessionStorage`，重进页面能恢复；原生未做本地保存（后端只有"按 id 取草稿"，没有列表接口），离开页面后草稿不再显示，只能重新生成。
5. **知识助手入口位置**：网页是页头「问知识助手」文字按钮；原生放在顶部导航栏图标（无障碍提示"问知识助手"），点击跳 `/knowledge/chat`（内容由 T07 提供，本期是占位页）。
6. **"更多"交互**：网页用折叠区展开；原生用底部操作菜单。
7. **授权管理**：网页是折叠区内的复选框列表；原生改为「管理总结授权」按钮 + 浮层开关列表（项目经理项固定为默认授权、不可关）。
8. **按钮字号**：320 窄屏 + 系统 200% 字号时，底座 `AppButton` 单行文案会被裁；本任务在按钮子树内把字号放大封顶到 1.3 倍（页面正文、列表、浮层文字仍按系统字号渲染）。这是适配取舍，不是文案差异。

文案层面保持与网页一致，且**全程没有出现 "wiki"、"ReactFlow" 等技术词**：来源类型显示为"我的笔记/我的材料/上传文件/我的汇报/与 AI 的交流/项目知识总结"，共享页显示为"AI 整理 · 已发布 / 项目共享笔记"。

## 七、发现的接口问题

1. **接口路径与 OpenAPI 完全一致**（用 `GET /openapi.json` 逐条核对）：`GET/POST /projects/{id}/personal-knowledge(+/entries,/links,/sync,/assist,/assist/apply)`、`GET /projects/{id}/knowledge-space(+ /grants/{user_id}, /summaries, /summaries/{id}, /summaries/{id}/save)`、`POST /asr/transcribe`。无需后端改动。
2. **错误信封两种形态**：业务错误走 `{"detail": "中文说明"}`（如成员资格 403），底座 `ApiClient` 已能把 `detail` 转成中文 message，前端直接展示，不吞异常。这一点用测试账号 `e2e_user` 实际调用确认：
   ```text
   GET /api/v1/projects/1/personal-knowledge  -> 403 {"detail":"需要在职公司成员与当前项目成员资格"}
   GET /api/v1/projects/1/knowledge-space     -> 403 {"detail":"需要在职公司成员与当前项目成员资格"}
   ```
3. **`/asr/transcribe` 需要 `project_id` 且校验 `evidence.submit` 权限**；当前环境 ASR 未配置，返回 503「语音转写服务尚未配置…」，前端会把后端中文原样显示（有测试覆盖）。属环境未配置，不是接口缺陷。
4. **`/assist` 在本人笔记少于 2 条时直接返回空建议且不调用模型**（`analyzed` 为条数），前端据此给出"再积累几条笔记就能发现更多关联"，与网页一致；AI 未配置时返回 409「资料已保留，请先在设置中启用 AI…」，前端展示该提示、不造假建议。
5. **总结接口没有列表**（见 S3-4），是本期原生"草稿不可恢复"的唯一根因。
6. 未发现需要后端修改的字段缺失或类型不符问题。

## 九、其他说明

- 所有异常路径都有可见状态：断网（`NetworkException` → "网络连接异常" + 重试）、403（`AppErrorState(isForbidden: true)` → "暂无访问权限"）、服务端 4xx/5xx（显示后端中文 message + 重试）、登录过期（`AuthException` → 由底座路由守卫回登录页）。没有 `catch {}` 静默吞异常。
- 时间处理：条目更新时间、共享页更新时间都用 `core/time/time_utils` 的 `parseApiDateTime` → `formatDisplayDateTime`（UTC 进、本地出）。
- 危险操作（删除笔记、删除关联）均二次确认；编辑浮层有未保存内容时返回会二次确认。
