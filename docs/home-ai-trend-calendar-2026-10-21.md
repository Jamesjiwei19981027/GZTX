# 首页 AI、趋势与日历更新验收

本次按已确认方案同步修改桌面 Web 与正式 Flutter APP 的共享界面。底部五个 Tab 保持工作、人轴、知识、消息、我的。

## 页面行为

首页主体顺序为：AI 汇报与助手 → 待办／今日到期／逾期三张卡片 → 任务趋势 → 当月日历 → 项目进度 → 新建任务 → 重点待办。管理者仍保留风险与团队视图。

- AI 区域提供“告诉 AI 最新进展”和“查看汇报”。前者打开个人项目助手，后者打开汇报中心；选择全部项目时仍需指定项目才能产生项目 AI 上下文。
- 三张数字卡片继续直接进入对应范围的任务看板，支持切换列表、更多进入回收站。
- 趋势图默认本周，可切本月，展开统计详情后可查看本季度与每日数据。按自然周／月／季度起始日至今天计算，日期按设备时区归桶。
- 统计与首页保持相同任务可见权限：本人拥有或被指派；指定项目时包括该项目和个人待办。“全部”显示全部可见任务。
- 趋势中的“完成”按实际完成日期计算，包括以前创建、本周期完成的任务；详情状态数按本周期新建任务计算。首页数字卡片包含全部日期的任务，因此两者不必相等。
- 网络失败显示重试，切换项目不会继续显示上个项目的图表。逾期是未完成任务中的子集，不重复计入状态比例条。
- 日期单击选择并显示安排；同一日期双击／双点新增一次，预填该日期，包含过去日期和相邻月份的日期。保留“添加当天日程”入口，禁用双点缩放。
- 点击任务时间／标题可改期。清除日期也会保留修改记录。编辑内可展开“日程修改记录”，查看首次记录时间和每次变更。
- 移除手机首页右上角“记录”及“快速记录一个待办事项”栏。桌面原快速添加与 Alt+N 继续可用。

## 修复

1. 全部项目中的快速添加保留个人归属，发送 `project_id: null`、`origin: personal`，不再自动使用第一个项目。
2. Web、APP、请求层和后端均保留真实 `quarter`，不再替换成 month；统计详情显示完整周期。
3. 趋势查询补计以前创建、近期完成的任务，并按设备日期边界归桶。
4. 编辑已完成任务但未改变完成状态时，保留原完成时间，避免改期后把完成数错误计入今天。
5. 日程历史覆盖单条修改及批量顺延；复核发现的批量顺延变量位置错误已回归修复。

## 数据与部署

新增只读历史表 `task_schedule_changes`，迁移 head 为 `fk9f0a1b2c3d`，前序为 `fj8e9f0a1b2c`。发布时先执行 `alembic upgrade head`，再启动服务。本地隔离联调库已完成迁移；本次未部署生产。

`GET /tasks/{id}/schedule-history` 使用任务可见权限校验；无法读取他人不可见任务的记录。历史从本功能启用后保留，不能还原之前未记录的变更。任务改期不修改已有汇报的 JSON 快照。
