## 后续反馈与首页补充

- **工作首页直接展示日程**：Web 和 APP 共用首页概览组件，待办摘要置顶，下面是默认展开的当月整月日历，再下面是正式项目进度简介，任务新建入口位于进度之后。小程序首页同步当月日历和项目进度。

- **项目与联系人各自独立成页**：工作首页项目名称按钮进入项目列表；消息加号进入独立的“工作联系人”页面。联系人页有自己的标题、返回与搜索，不再显示在项目界面或底部弹层内。小程序新增 `pages/contacts/contacts`。
- **曲线语义纠正**：APP 人轴从圆角折线路径改为三次贝塞尔曲线。回归直接检查 SVG 的 `C` 曲线命令，并在鼠标尚未松开时多次检查路径变化及源连接点与卡片连接点重合。
- **截图中的侧边浮条与键盘**：已确认是 Gboard 的触控笔手写工具条。已关闭该输入法偏好并保留系统软键盘。Flutter 壳使用 `adjustNothing`、`resizeToAvoidBottomInset:false` 和固定底部安全区，真实触摸验证确认键盘覆盖显示，页面 `innerHeight` 不因键盘缩小。

- **项目详情与人轴**：项目详情顶部显示成员邀请，任务待办和看板默认展开并加载项目内全部可见任务；人轴入口切换到人轴 Tab，不再跳回工作首页。人轴卡片继续用动态三次贝塞尔曲线跟随拖动。
- **主轴/次级人员**：服务端区分 `node_origin=project/subordinate`，人员最多三级。项目经理可管理主轴；次级人员由所属主轴负责人管理，项目经理可查看但不能越过所属主轴删除。删除前必须读取影响预览令牌，选择交接或明确级联确认；级联会撤销项目频道/群聊访问，历史汇报保留，任务按规则交接或进入回收站。
- **材料与个人智能体**：材料提交只保留文件和配文，材料类型由文件自动推断。上传文件与公司、项目、上传者绑定；汇报上下文会装载该用户项目内已抽取正文，交互式智能体也只检索当前用户当前项目的私有材料。
- **AI 汇报项目选择**：个人 AI 汇报中心、汇报编辑器和桌面报表均可切换具体项目；切换项目会清理旧项目草稿、聊天回复和延迟请求，避免跨项目上下文混入。
- **手机验证**：Web/APP 账号安全页使用绿色“已验证”和灰色“未验证”。APP 每次启动/恢复会在首次未验证后的七天窗口内提醒，绑定成功后停止；小程序启动也执行同一窗口规则。

## 用户可见的变化

1. **工作页按钮区分**：保留一处全局搜索；快捷记录使用 AI 图标和“记录”文字；新建任务使用编辑图标和“新建任务”文字。工作台不再重复展示两组搜索和加号。
2. **人轴总览**：改用可拖拽节点画布。每张个人卡片可以独立移动，平滑连线实时跟随两端；支持横向、纵向、画布平移、双指缩放、定位本人和重置布局。拖动调整当前画布中的展示位置，直属上级关系仍由项目经理管理。
3. **标题避让**：项目选择器移至标题下方的独立一行，长项目名不再遮挡“项目全貌”。人轴选择器显示实际加载的具体项目。
4. **人员管理权限**：新增下级按目标节点的服务端 `can_add_subordinate` 权限显示和校验。项目经理、超级管理员、有效管理委托，以及主责人员获准的责任分支可以管理下级；仅有协作身份不自动获得新增下级权限。直属上级变更仍只允许项目经理或超级管理员；普通人员的上级字段不可修改。后端在创建、移动和更换负责人时拒绝“自己担任自己的直属上级”。
5. **工作联系人与私聊范围**：普通成员可以主动联系同项目中的直属领导、直属下级、同级同事；顶层负责人可联系项目经理。项目经理可以主动联系其项目成员。普通成员不能越级发起私聊，也不能仅凭同公司身份向无关人员发起私聊。联系人来源和会话创建使用同一后端规则。项目频道继续承载共同讨论。
6. **消息加号**：现在打开“工作联系人”，选择具体人员后进入私聊。通知与收件箱有独立铃铛入口。Web 发送消息时也不再默认选中第一个成员；尚未选联系人时保留草稿并提示选择。旧公共频道“私信与提及”改为明确的“公共提及频道”，历史消息保留。
7. **深色模式**：修正 Tailwind 的深色选择器，使手动深色设置驱动实际组件样式，并同步浏览器颜色方案。即使 Android/浏览器系统偏好为浅色，手动深色仍能生效；切回浅色也会恢复实际颜色。

同时修复两个在回归中发现的问题：没有人员节点的项目经理不再被错误标记为第一位员工；编辑顶层人员资料不再暗中提交“把自己设为上级”的请求。

## 三端同步范围

- **Web 与 Android APP**：使用同一联系人组件、会话 API 和权限 API；Android 实际运行的是 Flutter APK 中的 WebView，本轮直接在该 APK 内通过 adb 触摸和滑动验证。
- **微信小程序**：消息页新增“新建私聊 → 工作联系人 → 选择人员”的入口，使用相同的联系人与会话创建接口。已验证页面逻辑和 JavaScript 语法；本轮没有微信开发者工具中的点击验收证据。
- **后端**：所有客户端都受创建会话、创建下级及移动节点的服务端校验约束。
