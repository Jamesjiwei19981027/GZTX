# 隐私政策补充：安卓系统推送

本应用为受邀用户提供团队任务、进展材料、知识和消息服务。通知落地页遵守原有账号、公司和项目权限。

当服务器启用系统推送、App 构建配置了 AppKey，且你已同意隐私政策后，我们才初始化极光推送 SDK，用于在安卓系统通知栏投递任务、材料和汇报提醒。未配置或未同意时不初始化 SDK，不影响原有站内通知。

SDK 名称：极光推送 SDK（JPush）；提供方：深圳市和讯华谷信息技术有限公司。SDK 为设备识别、推送连接、消息送达与点击统计，可能处理设备标识（Android ID、OAID 等，依实际系统授权与 SDK 配置）、设备型号、操作系统版本、网络状态与 IP 地址、Registration ID、消息送达及点击记录。我们不向 SDK 提供账号密码、服务器 MasterSecret 或任意业务附件。推送标题和摘要可能出现在锁屏，请在安卓系统通知设置中按需要关闭锁屏内容展示。

你可以在“我的 → 通知设置”关闭系统推送，或在安卓系统设置中撤销通知权限。退出账号时应用注销本机推送设备、停止接收并清除本机通知。重新登录后按当前账号重新登记；通知偏好与网页同步。

[极光隐私政策](https://www.jiguang.cn/license/privacy)、[极光 SDK 合规指引](https://docs.jiguang.cn/jpush/client/jghgzy_a_i_h)。

小米、华为、OPPO、vivo、荣耀厂商 SDK 当前未接入；后续启用前应同步补充相应服务提供方、数据处理说明和隐私授权提示。
