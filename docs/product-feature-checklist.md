## 2. Web 页面与按钮清单

### 2.1 认证和工作区

| 页面 | 入口/按钮 | 功能逻辑 | 完成标准 |
|---|---|---|---|
| 登录 | 用户名/邮箱/手机号、密码、登录 | 登录后保存 access/refresh token，失败保留输入并展示后端错误 | 可登录、刷新、退出，401 可无感续期 |
| 登录 | 验证码登录、发送验证码 | 发送验证码有冷却；验证码成功后建立会话 | SMTP/短信配置缺失时显示真实错误 |
| 注册 | 注册、邮箱验证码 | 校验密码、邮箱唯一性，成功进入验证门 | 不产生重复账号 |
| 验证门 | 重发、确认、退出 | 未验证用户只能验证或退出；确认后恢复原入口 | 验证状态跨端一致 |
| 手机验证 | 发送、确认、继续原动作 | 创建公司、接受邀请、协作前拦截；验证后继续 | 原动作不丢失 |
| 首屏 | 启动同步、重试 | 并发加载用户、公司、项目、任务、分类、标签、UI 偏好 | 失败不注入假数据 |
| Navbar | 项目选择器 | 切换项目上下文，影响任务、消息、人轴、汇报 | “全部项目”只做个人总览 |
| Navbar | 搜索 | 搜索任务/项目，点击结果进入详情或人轴 | URL/返回键可恢复 |
| Navbar | 新建任务、快速添加 | 完整表单或自然语言解析后创建任务 | 创建失败保留输入 |
| Navbar | 通知、语言、设置、退出 | 打开通知、写语言偏好、跳设置、撤销会话 | 读写状态跨端同步 |
| 主导航 | 工作、人轴、知识、消息、我的 | Web 与 APP 五个主入口一致；工作下收敛到任务管理 | 旧深链及返回仍有效 |

### 2.2 任务和日历

| 页面 | 入口/按钮 | 功能逻辑 | 完成标准 |
|---|---|---|---|
| 工作首页 | 顶部待办／今日到期／已逾期 | 进入对应范围的任务看板 | 范围与统计一致；完成任务排除 |
| 任务管理 | 看板／列表切换、范围、更多 | 同一任务区切换展示；更多进入回收站 | 往返保留范围，恢复即时更新 |
| 首页日历 | 选日期、点时间／任务、添加当天日程 | 直接修改日期和时间；按选中日期新增，显示当天全部安排 | 保存与刷新一致，失败保留输入 |

| 我的任务 | 筛选、全选、批量完成 | 按状态、优先级、今日组合过滤；批量写回 | 部分失败有反馈 |
| 我的任务 | 批量顺延、批量删除 | 批量改截止日期或软删除，可恢复 | 不误删数据 |
| 看板 | 四列、筛选、拖拽 | 拖动任务改变状态；完成列复用完成逻辑 | 移动端提供替代按钮 |
| 看板 | 列内新建、卡片菜单 | 以目标状态新建；详情/完成/删除 | 菜单不误触卡片 |
| 日历 | 上月、下月、今天 | 移动月份游标并重新计算日历 | 时区正确 |
| 日历 | 月/周/日/时间线 | 切换布局，按截止日期和时间放置 | 跨日、无时间任务正确 |
| 日历 | 日期格新建、任务点击、拖动改期 | 预填日期；查看详情；拖动改截止日期 | 更新失败提示 |
| 日历 | ICS 导出、订阅、重置订阅 | 导出日历或生成可撤销订阅地址 | Token 可撤销 |
| 任务详情 | 标题、描述、状态、优先级、负责人 | 即时/失焦更新；完成/恢复/删除 | 抽屉与列表同步 |
| 任务详情 | 子任务、标签、附件、责任节点 | 编辑子任务、标签、附件和人轴绑定 | 后端再次校验权限 |
| 快速添加 | 自然语言、解析预览、提交 | 解析标题、日期、优先级、标签，用户确认后创建 | 解析失败保留原文 |

### 2.3 团队、消息和通话

| 页面 | 入口/按钮 | 功能逻辑 | 完成标准 |
|---|---|---|---|
| 团队 | 成员、角色、邀请、移除 | 管理公司成员及项目成员 | 公司/项目权限隔离 |

| 消息 | 新建频道/私聊/群聊 | 创建协作空间并刷新列表 | 成员权限后端校验 |

| 消息 | 点赞、固定链接、文件下载 | 更新消息互动或频道资料 | 操作可重试 |
| 消息 | AI 总结 | 总结当前群聊或私聊，输出要点、决定、待办、风险 | 显示 provider 和来源条数 |
| 消息 | 语音/视频通话 | 创建会话，交换 WebRTC 信令，显示本地/远端媒体 | HTTPS、TURN 和权限齐备 |

| 收件箱 | 通知筛选、搜索、已读、归档、删除 | 更新通知状态并按 payload 跳转 | 未读数同步 |
| 收件箱 | 快捷回复、转任务 | 回复通知或将来源内容带入任务草稿 | 来源元数据保留 |
| 外部邮件 | 同步、打开、归档、删除、恢复 | 按配置同步 IMAP/外部邮件 | 不自动伪造同步成功 |

## 6. 统一验收门槛

- 所有读取和写入必须经过公司、项目和人轴权限校验。
- 每个项目的智能体上下文、消息、资料、知识和缓存必须隔离。
- AI 输出必须能标明来源、时间、provider 和失败原因。
- Web、Flutter、Android、iOS、小程序共享服务端状态，不能维护互相矛盾的业务副本。
- 真实 LLM、ASR、TURN、SMTP、微信 AppID、对象存储和签名证书属于生产依赖，未配置时必须显示真实未配置状态。
