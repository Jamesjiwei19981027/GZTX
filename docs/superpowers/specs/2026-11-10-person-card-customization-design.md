# 人轴人员卡片自定义

## 目标与约束

按最大用户自由度实现三层配置，优先级为个人视图 > 单人卡片 > 项目模板 > 系统默认。不提交 Git，不修改 Docker、代理或 8010/8088/8097/8099 服务；不新增依赖。复用既有树形、项目隔离、审计和 ui-prefs。网页桌面、手机网页、原生 Flutter 与 Web Shell 使用相同契约，小程序不在本期。

## 配置契约

- `projects.card_template_json`：`fields` 为有序的可见字段数组，`density` 为 compact / standard / detailed，`color` 为固定色板键。只有项目 PM（包括成员角色 pm）与 created_by 可改。
- `tree_nodes.card_style_json`：仅 person，支持 `color`、`tags: [{text,color}]`、`custom_fields: [{key,value}]`、`fields`、`avatar: initial | profile`。本人指 primary/collaborator 责任人，直接上级指直接父人员节点 primary 责任人；PM 与创建者可改。祖先、委托、公司管理员身份不自动扩大权限。
- `ui-prefs.person_cards[项目编号]`：支持 `fields`、`density`、`show_colors`、`show_tags`。写入只合并本次提供的项目键，其余项目不覆盖；空对象恢复该项目个人默认。
- 省略键表示继承，空 `fields: []` 表示明确隐藏全部可选内容；数组整体替换。姓名即便被隐藏，仍通过操作入口与辅助技术名称识别人，折叠行始终显示姓名。
- 固定字段：avatar、name、role、department、description、task_count、overdue_count、progress、recent_progress、next_due、tags、custom_fields。
- 标签最多 8 个，非空且不超过 12 个 Unicode 码点；自定义字段最多 10 个，键非空且不超过 12 字，值允许留空且不超过 60 字。允许相同键和值以保留自由度。配置禁止任意 CSS、URL、未知键和重复显示字段。
- 关闭颜色同时取消标签配色，关闭标签优先于显示字段设置。卡片恢复项目默认以 PUT 空对象清除覆盖；不会删除个人视图偏好。

## 配色与头像

纸与墨规范仅定义语义色，未给出需求所称八色色板。本实现补充 ink 墨蓝、slate 岩灰、sage 鼠尾草、ochre 赭石、clay 陶土、rose 灰玫瑰、plum 灰梅、stone 石灰，使用固定低饱和点色和浅底，正文沿用主题文字色，不做彩色左边条。

复用用户既有 profile 头像及现有头像管理入口；卡片编辑只选择已有头像或名字首字，不新增附件上传授权与公共访问链路。此处与“没有就只做首字”的意图一致，但不提供独立卡片图片上传。

## 数据与交互

迁移 `fs7a8b9c0d1e` 接已核实 head `fr6f7a8b9c0d`。支持旧库新增列及基线 metadata.create_all 已含列的新库。读取随项目详情和 tree 返回；tree 附服务端卡片编辑能力。写路径统一走 TreeService，事务内保存 before/after 审计，不修改责任树结构。

项目设置内增加卡片模板入口，编辑区域右侧（窄屏上方）实时预览。卡片“更多”增加编辑卡片，抽屉保留保存失败后的草稿，提供恢复项目默认。工具栏增加显示设置，单独控制个人偏好。字段可开关、拖动排序，并提供上移/下移供键盘和触屏使用。原生 Flutter 使用底部弹层与可重排列表。

渲染显示真实任务数量、逾期数量、平均进度、最近进展和未完成事项最近截止时间，缺失内容显示空状态，禁止伪造业务数据。折叠和拉到人轴算法沿用原实现；折叠行的内容按本期需求改为姓名、颜色圆点、首个标签，替代旧的角色/任务数/逾期列。个人隐藏颜色或标签仍生效。人员身份的辅助技术名称不随可见字段隐藏。

画布卡片沿用既有固定占位尺寸，以免破坏责任树连线与折叠布局。超过卡片高度的自由字段在卡内滚动；密度控制字段字号与间距。原生配置卡片支持内容滑动，长按拖动位置与调整上级。详情页保留完整身份、业务操作与独立卡片编辑入口。项目模板预览不应用单人覆盖，个人预览应用该人的样式。

## 分阶段验收

1. 后端：先失败测试，再迁移、校验、权限、审计、读取和偏好合并；运行全量 pytest 后进入网页阶段。
2. 网页：共享配置合并、编辑器和卡片内容，接桌面与手机入口；合并单测、SSR/交互检查、lint 和 npm test；再进入 App 阶段。
3. App：同字段与色板、读取、合并、编辑和项目/个人入口，widget 与数据测试，flutter analyze 和 flutter test。可用时在既有安卓模拟器操作；不操作指定服务。
4. 报告包含真实门禁末尾输出、未验收设备与设计偏差。iOS 真机和微信设备不冒充已验收。
