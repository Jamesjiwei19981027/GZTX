# 工作重点待办与人轴直接入口

本次同步修改桌面 Web 与正式 APP 使用的共享 React 页面。未改动 Flutter 原生壳或后端权限规则。

## 用户能看到的变化

- 工作页在项目／用户信息下首先展示“重点待办与跟进”，然后是 AI 汇报入口、待办统计、趋势、日历及项目进度。员工与管理者模式均可看到重点待办。
- 两端展示最多 5 项未完成任务，按截止日期排序；未设置截止日期的任务仍保留，排在有日期的任务之后。点击任务打开详情。
- 人轴页选定项目后直接展示“委托授权”“AI 责任链审计”，无需打开画布设置。在“我的职责”“项目全貌”之间切换时入口仍可使用。
- 委托授权说明明确：授权对象是指定人员，范围是系统内该项目的勾选操作；查看材料针对已上传的项目材料，不授予手机或电脑本地文件访问权限。
- 项目成员可查看授权记录。创建授权由项目经理／公司管理员操作；撤销遵循原有后端规则，管理员或授权发起者可撤销。
- APP 授权使用人员选择、与 Web 相同的操作清单；删除固定演示授权详情与未提交的演示开始时间，记录中以中文显示授权操作。
- “编辑人轴”的现有委托范围实际为项目范围，页面明确标注全项目范围；移动／删除人员仍由独立权限约束。
- 两端有效期按用户本地所选日期的 23:59:59 换算为 UTC 提交；不填写表示长期。修复 APP 原先按 UTC 零点提交造成所选日期提前失效的问题。
