## A. 与现网模型关系

| 现网 | 升级后 |
|------|--------|
| `users` | 保留；个人底盘所有者 |
| `tasks` | 保留；`origin` 默认 `personal`；可选 `project_node_id` 作投影链接（非正式进度） |
| `attachments` | 可被 `evidence_files` 复用 `storage_key`；正式材料以 `evidence_packages` 为准 |
| `reminders` / 邮件闭环 | 保留服务 personal；项目催办走 `notify_jobs` + Notification Service |
| 路由 `/tasks` | **永久保留**；新增 `/projects` 等；不强制改写为 `/personal` |

**兼容策略**：旧客户端只打 `/tasks` 不受影响。新 Web 同时调项目 API。禁止用更新 `tasks.status` 冒充项目正式进度。

## D. 状态机

### D.1 EvidencePackage

```
draft
  → (submit + 个人智能体预检失败) → precheck_failed → draft
  → (submit + 预检通过) → submitted → judging
        → adopted
        → rejected
rejected
  → (二次上传新包 supersedes=旧包) → 新包 draft/submitted...
  → (旧包) status 可标 superseded（当新包 adopted 时）
```

**不变式**：adopted/rejected/submitted/judging 的 summary/files 不可被提交人改写。

### D.2 ReviewCase（复核 / 更正 / 增量补充）

```
open
  → agent_concluded（智能体出结论，可倒逼 PM 补信息，仍保持可回到 open 补 supplement）
  → awaiting_pm
  → confirmed  → 触发「四件事」事务
  → dismissed
```

### D.3 正式进度写入路径

| 路径 | 条件 | source |
|------|------|--------|
| A 自动 | 材料 judging 且 PM agent 输出 adopted | pm_agent_auto |
| B 澄清文本 | allow_clear_text_progress 且个人 agent 验收模板通过 | executor_clear_text |
| C 人确认 | review_case confirmed | human_pm_confirm |
| D 更正 | 更正案 confirmed | correction |

**写进度步骤（事务）**：  
1) INSERT progress_records  
2) UPDATE tree_nodes.progress_json = after_json  
3) 若 scope 祖先：异步/同步 recompute  
4) INSERT audit_logs `progress.auto_write` 或对应 action  
5) 频控检查 → 可能 notify 告警  

### D.4 Scope 汇总算法（默认）

```
对 scope 节点 N：
  children = 直接子节点中未删除者
  work_items = 子树内 template=work_item 的节点（默认仅直接子 + 嵌套 work_item，配置 rollup_mode）
  total = count(work_items)
  done = status==done
  blocked = status==blocked
  milestones_* 同理统计子树 milestone
  写入 progress_json.summary
```

默认 `rollup_mode = subtree_work_items`。禁止环：插入/移动节点时校验 path 不包含自身。

## L. 验收用例示例（Given/When/Then）

**E2E-01 材料自动采纳**  
Given：用户 U 为项目 P 成员，节点 N 为 work_item，不允许 clear_text；U 上传文件并 submit  
When：worker 完成 `evidence.judge` 且模型输出 adopted  
Then：package=adopted；progress_records+1 source=pm_agent_auto；node.progress 更新；wiki 有沉淀；U 与 PM 收到通知；audit 有 progress.auto_write  

**E2E-02 未采纳二次上传**  
Given：package 被 rejected  
When：U 不传新文件仅改文字  
Then：400/422 要求新 package；When 二次上传 supersedes 后可再判  

**E2E-03 越权**  
Given：非成员  
When：GET 材料详情  
Then：403  

**E2E-04 离职收权**  
Given：成员 employment=left  
When：同步 job  
Then：project_members.left_at 非空；后续 evidence.submit 403；历史 progress 仍在
