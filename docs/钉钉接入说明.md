# 钉钉接入说明

本文适用于本机局域网内测。应用访问地址使用 `APP_URL` 配置，例如 `http://192.168.1.20:8080`；钉钉开放平台暂时登记的完整回调地址必须为：

```text
${APP_URL}/api/v1/sso/dingtalk/callback
```

例如 `APP_URL=http://192.168.1.20:8080` 时，应填 `http://192.168.1.20:8080/api/v1/sso/dingtalk/callback`。内测时电脑和钉钉客户端必须能访问该局域网地址，防火墙须允许访问服务端口。配置 `APP_URL`、钉钉回调地址和浏览器实际访问的主机、端口及协议必须完全一致。公网生产上线前需按钉钉要求使用备案域名和 HTTPS。

## 一、创建企业内部应用

1. 使用企业管理员账号打开[钉钉开放平台](https://open.dingtalk.com/)，进入企业内部开发并创建企业内部应用。不要选择第三方企业应用或个人应用。
2. 设置应用名称、图标、可见范围；需要扫码登录的企业成员须在应用可见范围内。
3. 在应用开发管理中配置 OAuth 回调地址，精确填写本文开头的完整地址；不要填写只有域名的地址，也不要使用 `localhost`。
4. 保存应用，按钉钉流程发布或启用应用。分别记录应用凭据中的 `AppKey`、`AppSecret`、`AgentId` 和企业 `CorpId`。`AppSecret` 仅在服务端输入一次，不要放到网页代码、工单或聊天记录中。

## 二、申请所需权限

在应用权限管理中申请并发布以下权限。钉钉控制台的中文名称或权限点可能随应用类型调整，请以当前应用中能调用以下接口所要求的读权限为准：

| 用途 | 控制台权限/权限点 | 对应调用 |
|---|---|---|
| OAuth 用户身份、unionId、昵称 | 用户信息读取；`Contact.User.Read` | `GET /v1.0/contact/users/me` |
| OAuth 用户手机号 | 用户手机号读取；`Contact.User.mobile` | `GET /v1.0/contact/users/me` |
| OAuth 用户邮箱 | 用户邮箱读取；`Contact.User.email`（若控制台拆分展示） | `GET /v1.0/contact/users/me` |
| 企业部门信息 | 通讯录部门只读；`qyapi_get_department_list` | `topapi/v2/department/get`、`topapi/v2/department/listsub` |
| 部门成员及成员资料 | 通讯录部门成员只读 `qyapi_get_department_member`、成员信息只读 `qyapi_get_member` | `topapi/v2/user/list` |
| 目录成员手机号/邮箱（用于匹配既有成员） | 手机号 `fieldMobile`、邮箱 `fieldEmail`，按钉钉控制台实际权限页申请 | `topapi/v2/user/list` |

只申请通讯录读取范围，不申请创建、修改或删除通讯录成员的权限。将应用通讯录可见范围设置为需要同步的部门；同步账号只能读取该可见范围。权限审批、企业授权及应用发布完成后，再验证应用凭据和范围。

## 三、录入 WorkTodo

1. 管理员登录 WorkTodo，进入“设置 → 企业管理 → 组织与登录”。
2. 在“钉钉企业内部应用”填写 `CorpId`（企业标识）、`AppKey`（应用标识）、`AgentId`（应用编号）、`AppSecret`（钉钉应用密钥），保存配置。
3. 页面显示由当前服务端 `APP_URL` 生成的完整授权回调地址；逐字与钉钉应用登记值核对。
4. 在企业登录方式中启用“钉钉登录”。钉钉用户授权后，系统优先按企业内已绑定的 `unionId` 匹配，再按企业邮箱、手机号匹配已邀请的在职成员。匹配不到时提示联系管理员邀请；不会自动开户。
5. 点击“钉钉立即同步”。页面显示最近同步时间、新增、更新、失败和未关联账号数量。同步更新企业部门和人员通讯录记录；只链接已有企业成员，不创建用户账号、不自动邀请，也不按单次同步结果自动删除本地用户。

应用密钥通过服务端加密保存；设置页与列表接口不回显密钥。若更换应用密钥，请在密钥输入框输入新值后保存；留空表示保留现有值。

## 四、内测范围与排错

- 当前启用范围为单企业部署的默认企业，避免全局用户令牌跨企业信任不同企业的身份提供方。同一用户若在多个企业有效任职，暂不提供企业 SSO 登录。
- 浏览器的 OAuth `state` 通过一次性随机数与发起浏览器绑定；回调票据短期、一次性使用，兑换前令牌不会放在 URL 中。
- “企业微信”“飞书”“联合身份认证（SAML）”显示为下一期支持，本期接口也拒绝保存或启用。
- 回调报错：核对钉钉控制台地址与 `APP_URL` 的协议、IP/域名、端口、路径是否完全一致，并确认手机可以访问该局域网 IP。
- 获取令牌或通讯录失败：核对 `AppKey` / `AppSecret` / `CorpId`、权限审批与发布状态、应用可见范围和服务端网络连通性。检查服务端日志时不要输出授权码、令牌或密钥。
- 登录提示邀请：先在 WorkTodo 企业成员管理中邀请用户加入，并确保账号邮箱或手机号与钉钉通讯录一致；确认员工处于在职状态。

本期 Web / APP 共享网页外壳内的布局与票据回调已自动化验证。因当前受限环境无法连接安卓模拟器，本次未完成模拟器实机扫码、iOS 或微信设备验收。
