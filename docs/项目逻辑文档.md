## 一、一句话定位

**WorkTodo（产品品牌：烂笔头 PM）** 是一套**自托管**工作待办提醒系统，并正在**同一产品内加层**扩展团队协作能力：

- Web（React 19 + Vite，现役）与微信小程序共用 **FastAPI** 后端；
- JWT 认证；中心库 + REST（无独立 Sync 协议）；
- 定时任务：提醒推送、邮件回执处理、每日摘要；
- **已落地协作层**：项目管理树、证据化正式进度、任务责任人、团队频道/私信、二进制附件、通知收件箱、浏览器 WebRTC 信令和可选 IMAP 适配器。更大范围的组织对接与 License/线上开通仍按规格逐步扩展。

**现役主路径**是个人待办 + 提醒，并叠加真实 API 驱动的看板、团队聊天、协作收件箱和人轴；**不**用个人 `tasks.status` 冒充项目正式进度。

## 四、后端逻辑

### 4.1 入口

- `backend/app/main.py`：CORS、生命周期、APScheduler、路由挂载
- 健康检查：`GET /api/v1/health`

### 4.2 已挂载路由（`/api/v1`）

| 模块 | 能力 |
|------|------|
| `auth` | 注册、登录、微信登录、刷新、登出 |
| `tasks` | 列表筛选、今日、统计、CRUD、完成/撤销、批量 |
| `categories` / `tags` | CRUD（分类含排序） |
| `reminders` | 列表、创建、删除、今日 |
| `users` | 我的信息、改密、绑微信、邮箱状态 |
| `notifications` | VAPID、Web Push、测推送/邮件、SMTP |
| `attachments` | 上传/列表/下载/预览/替换/删除（**异步栈已对齐**） |
| `wx` | 小程序配置、订阅消息、订阅状态（**已对齐**） |

### 4.3 定时任务

| Job | 周期 | 作用 |
|-----|------|------|
| 邮件检查 | `EMAIL_CHECK_INTERVAL` | IMAP 指令处理 |
| 提醒扫描 | 60s | 到期提醒发送 |
| 每日摘要 | cron | 摘要邮件 |

### 4.4 领域模型（要点）

- **Task**：status 0/1/2，priority 0/1/2，软删除，完成评价与跟进字段，邮件回执计数
- **Reminder**：`remind_at` + `notify_channels`
- **Attachment / EmailReplyRecord / RecurringInstance**：已纳入模型导出与建表导入

## 五、前端逻辑（现役唯一 UI）

### 5.1 技术栈

React 19 + TypeScript + Vite + **Tailwind** + Recharts + Lucide（项目树与人轴由现役组件实现）

设计源：`UI/stitch_smart_task_manager/productivity_flow/DESIGN.md`  
行为对照：`frontend-vue-archive/`（Vue3 + Pinia + Element Plus，非现役）

### 5.2 页面范围

| 路由 | 页面 | 说明 |
|------|------|------|
| `/login` `/register` | LoginPage | 认证 |
| `/dashboard` | DashboardPage | 统计与临期（默认首页） |
| `/tasks` `/tasks/:id` | TaskList / Detail | 核心任务链路 |
| `/calendar` | CalendarPage | 日历 |
| `/settings` | SettingsPage | 资料、主题、SMTP、LLM、推送 |
| `/projects` `/projects/:id` | ProjectList / Detail | 协作项目（大纲树 + React Flow） |
| `/company/settings` | CompanySettingsPage | 公司 SMTP / LLM（管理员） |

侧栏导航含：**仪表盘 · 我的任务 · 日历 · 项目 · 设置** 等（以代码路由为准）。  
旧路径 `/inbox` `/kanban` `/chat` 兼容重定向到 dashboard/tasks。

### 5.3 核心前端模块

- `stores/task.ts`：任务与本地时间转换（Zustand）  
- `stores/auth.ts`：登录后进 `/dashboard`；token 键 `localStorage.access_token`  
- `routes/RequireAuth.tsx`：路由鉴权守卫  
- `components/project/*`：大纲树、React Flow、证据、Agent 抽屉  
- `pages/SettingsPage.tsx`：个人 SMTP / LLM（密钥不回显、空串不覆盖）

## 七、主流程速查

1. **注册** → 默认分类 → Token → 仪表盘  
2. **建任务 + 提醒渠道（含 email）** → 落库 Reminder  
3. **调度** 到期 → Web Push / 邮件等  
4. **完成** → 可带评价与跟进  
5. **邮件回复指令** → IMAP 解析 → 改任务
