## 一、一句话定位

**WorkTodo（产品品牌：烂笔头 PM）** 是一套**自托管**工作待办提醒系统：

- Web（Vue3）与微信小程序共用 **FastAPI** 后端；
- JWT 认证；中心库 + REST（无独立 Sync 协议）；
- 定时任务：提醒推送、邮件回执处理、每日摘要。

**不是**协作型项目管理 SaaS：看板 / 团队聊天 / 企业收件箱已从现役前端移除（原为 Mock）。

## 三、能力分层

```
L0 身份：注册/登录/刷新 Token / 微信登录 / 绑定邮箱
L1 任务：CRUD · 状态 · 优先级 · 分类 · 标签 · 软删除 · 统计 · 完成评价 · 跟进
L2 提醒：Reminder · 多通道（web_push / email / …）· Web Push · SMTP · 每日摘要
L3 邮件闭环：提醒邮件 → 回复指令 → IMAP → 解析 → 改任务 → 确认邮件
L4 表现层：Web SPA · 小程序
```

## 四、后端逻辑

### 4.1 入口

- `backend/app/main.py`：CORS、生命周期、APScheduler、路由挂载
- 健康检查：`GET /api/v1/health`

### 4.2 已挂载路由（`/api/v1`）

| 模块 | 能力 |
|------|------|
| `auth` | 注册、登录、微信登录、刷新、登出 |
| `tasks` | 列表筛选、今日、统计、CRUD、完成/撤销、批量 |
| `categories` / `tags` | CRUD（分类含排序） |
| `reminders` | 列表、创建、删除、今日 |
| `users` | 我的信息、改密、绑微信、邮箱状态 |
| `notifications` | VAPID、Web Push、测推送/邮件、SMTP |
| `attachments` | 上传/列表/下载/预览/替换/删除（**异步栈已对齐**） |
| `wx` | 小程序配置、订阅消息、订阅状态（**已对齐**） |

### 4.3 定时任务

| Job | 周期 | 作用 |
|-----|------|------|
| 邮件检查 | `EMAIL_CHECK_INTERVAL` | IMAP 指令处理 |
| 提醒扫描 | 60s | 到期提醒发送 |
| 每日摘要 | cron | 摘要邮件 |

### 4.4 领域模型（要点）

- **Task**：status 0/1/2，priority 0/1/2，软删除，完成评价与跟进字段，邮件回执计数
- **Reminder**：`remind_at` + `notify_channels`
- **Attachment / EmailReplyRecord / RecurringInstance**：已纳入模型导出与建表导入

## 五、前端逻辑（现役唯一 UI）

### 5.1 技术栈

Vue3 + Vite + Pinia + **Tailwind（MD3 token）** + Element Plus（表单/弹窗）+ Material Symbols + Inter

设计源：`UI/stitch_smart_task_manager/productivity_flow/DESIGN.md`

### 5.2 页面范围

| 路由 | 页面 | 说明 |
|------|------|------|
| `/login` `/register` | LoginView | 认证 |
| `/dashboard` | DashboardView | 统计与临期（默认首页） |
| `/tasks` `/tasks/:id` | TaskList / Detail | 核心任务链路 |
| `/calendar` | CalendarView | 日历 |
| `/settings` | SettingsView | 资料、主题、SMTP、推送 |

侧栏导航仅：**仪表盘 · 我的任务 · 日历 · 设置**。  
旧路径 `/inbox` `/kanban` `/chat` 兼容重定向到 dashboard/tasks。

### 5.3 核心前端模块

- `stores/task.ts`：任务与本地时间转换  
- `stores/auth.ts`：登录后进 `/dashboard`  
- `components/ReminderSetting.vue`：提醒时间 + **邮件等通知渠道**  
- `composables/useWebPush.ts`：VAPID 订阅  
- `SettingsView`：SMTP 配置与测试邮件

## 七、主流程速查

1. **注册** → 默认分类 → Token → 仪表盘  
2. **建任务 + 提醒渠道（含 email）** → 落库 Reminder  
3. **调度** 到期 → Web Push / 邮件等  
4. **完成** → 可带评价与跟进  
5. **邮件回复指令** → IMAP 解析 → 改任务
