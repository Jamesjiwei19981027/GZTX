烂笔头PM

好记性不如烂笔头 · WorkTodo · 自托管工作待办与人轴责任链

进入系统

这是什么

给领导视角用的待办系统：主干是人，事项和里程碑挂在人下面，终责钉在项目 PM。 Web、微信小程序、Flutter APP 共用同一套 FastAPI 后端，数据在自己的服务器上。

能做什么

人轴责任链人为主干，事项挂载，终责收口
任务与看板优先级、分类、标签、子任务清单
提醒闭环网页 / 邮件 / 微信；邮件回复即可完成
协作公司、项目、指派、消息、收件箱

怎么开始

  • 自托管：仓库根目录 docker compose up -d，浏览器打开本机 80 端口。
  • 个人使用只需验证邮箱；邀请同事进项目才要求手机号。
  • 详细步骤见仓库 README 的「用户指南」和「部署指南」。
中文品牌名「烂笔头PM」，英文 WorkTodo。软件按 MIT 许可开源；商业部署的公司许可证口径见 README。
